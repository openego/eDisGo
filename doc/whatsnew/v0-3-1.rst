Release v0.3.1
================

Release date: not yet released

Changes
-------

* Corrected the Julia version documented in ``config_opf_julia.cfg``, which still
  pointed at ``julia-1.1.0/bin`` while the bundled ``eDisGo_OPF.jl`` package targets
  Julia 1.12. The file is included verbatim in the configuration reference, so the
  stale path was published in the documentation. Its ``julia_bin`` value has not been
  read since :meth:`~.edisgo.EDisGo.pm_optimize` started resolving ``julia`` from the
  system ``PATH``; the reference now says so instead of claiming the file points to the
  binary in use
* Documented the expected eTraGo-to-eDisGo data mapping of the overlying grid
  (:ref:`overlying-grid-mapping`): for each of the thirteen
  :class:`~.network.overlying_grid.OverlyingGrid` attributes, which eDisGo variable
  carries it into the optimisation, where the corresponding result appears, and which
  constraints between the two are expected to hold — intended as the reference for
  automated validation tests. Two attributes are documented as currently having no
  consumer in the production pipeline, and the class docstring, which listed only ten
  of the thirteen attributes, is completed
